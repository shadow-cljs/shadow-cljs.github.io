For new browser CI setups, use <<browser-test-headless, :browser-test with a headless browser>>. https://github.com/karma-runner/karma[Karma is deprecated upstream]. The `:karma` target remains available for existing Karma installations and adds the wrappers needed to run `cljs.test` tests.

=== Installing Karma

For an existing Karma project, install Karma, a browser launcher and the cljs-test integration:

```bash
$ npm install --save-dev karma karma-chrome-launcher karma-cljs-test
```

Consult the https://karma-runner.github.io/[Karma documentation] for configuration. The example below is a compatibility reference; verify the plugin versions against your project's Node.js and browser versions.

=== The Build

The build options are:

[horizontal]
`:target`::     `:karma`
`:output-to`::  A path/filename for the js file.
`:ns-regexp`::  (optional) A regex to match the test namespaces, defaults to `"-test$"`.

So you might have something like this:

```
{...
 :builds
 {:ci
  {:target :karma
   :output-to  "target/ci.js"
   :ns-regexp  "-spec$"}}}
```

You also need a `karma.conf.js`:

```javascript
module.exports = function (config) {
    config.set({
        browsers: ['ChromeHeadless'],
        // The directory where the output file lives
        basePath: 'target',
        // The file itself
        files: ['ci.js'],
        frameworks: ['cljs-test'],
        plugins: ['karma-cljs-test', 'karma-chrome-launcher'],
        colors: true,
        logLevel: config.LOG_INFO,
        client: {
            args: ["shadow.test.karma.init"],
            singleRun: true
        }
    })
};
```

Run the local tools:
